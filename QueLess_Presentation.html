01. The Problem

Why Physical Waiting Lines Fail Today

Traditional queuing creates bottlenecks, stress, and operational blindspots.

⏳
Lost Productivity & Anxiety

Customers spend 30–60+ minutes physically trapped in waiting rooms with zero visibility into when their turn will actually arrive.

📉
Unpredictable Waiting Times

Static paper tickets provide a fixed number without accounting for variable service durations, delays, or emergencies.

👥
Congested Waiting Rooms

Overcrowded lobbies create health risks in hospitals, chaotic environments in banks, and poor guest impressions in salons.

📊
Lack of Operational Analytics

Businesses lack real-time data to measure counter throughput, staff bottlenecks, peak hours, or customer abandonment rates.

02. The Need

Why Virtual Queuing is Crucial

Transforming idle waiting time into productive personal time.

  • Time Autonomy for Customers: Freedom to join a queue remotely, grab a coffee, run errands, and arrive right when their token is called.
  • Dynamic, Real-Time Transparency: Continuous live updates indicating exact position in line, current counter token, and estimated wait duration.
  • Smooth Staff Workflow: Digital call desks empower staff to call next tickets, handle walk-in entries, and manage multiple counters with 1 click.
  • Data-Driven Decision Making: Clear visibility into average consultation durations, daily queue loads, and counter efficiency.

04. How It Works

Seamless 4-Step Operational Flow

Synchronized in real-time between customer devices and business desks.

01
Discover & Join

Customer selects business service and joins live queue or books a scheduled slot remotely.

02
Live Tracking

Status shifts dynamically: Waiting → Approaching (Next in line) → Now Serving with wait estimates.

03
Voice & TV Callout

Staff calls next ticket. Lobby TV display pulses, chime sounds, and synthetic voice announces token.

04
QR Verify & Finish

Staff verifies digital QR token pass, completes service, and metrics log automatically.

05. Key Innovations

Cutting-Edge Features Built-in

Hardware-free, browser-native capabilities for enterprise-grade queues.

📺 Public Waiting Room TV Display

Dedicated fullscreen lobby mode (/display/:id) with high-contrast cards, counter tags, and upcoming ticket tickers.

🔊 Web Audio & Voice Synthesis

Zero external sound libraries. Uses native Web Speech API & Web Audio oscillator chimes ("Token 40, Counter 1").

📱 Digital QR Code Token Passes

Self-contained HTML5 canvas QR generator for rapid counter check-in and token authenticity check.

🔄 Resilient Dual-Mode Storage

Robust MySQL schema locally + instant automatic fallback to in-browser reactive mock database on GitHub Pages.

06. System Architecture

Clean, Modern Technology Stack

Engineered for low latency, zero bloat, and cross-platform flexibility.

⚛️
Frontend Tier

React 19 • Vite 7 • Lucide
Modern SPA with Error Boundaries, PWA manifest, and fluid responsive glassmorphism styles.

🚀
Backend API

Node.js • Express REST API
JWT role-based auth (customer vs staff), dynamic wait-time calculation, and queue transaction controls.

🗄️
Data Storage

MySQL 8.0 • LocalStorage
Indexed tables with transaction locking (FOR UPDATE) + zero-config in-browser mock engine.
